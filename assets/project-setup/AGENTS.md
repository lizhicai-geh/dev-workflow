# 项目 AI 自主开发规范

本项目使用 `autonomous_ai` 模式。AI 完成需求分析、计划、实现、审查、测试、文档和交付证据，不把开发步骤转交给用户。

## 项目事实

- 前端：`apps/web`
- 后端：`apps/api`
- 业务规则：`docs/business-rules`
- 数据库迁移：`migrations`
- 技术栈：React、TypeScript、MySQL 8（按项目修改）

## 质量命令

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

## 规则

1. 以业务规则、字段字典和 API 契约为准，不自行推断缺失规则。
2. 只修改任务相关文件；数据库变化新增迁移。
3. 不删除或弱化测试规避失败。
4. 所有验收标准绑定自动化检查；无法验证时阻断完成结论。
5. 实现后执行独立 AI 验证轮次，复核需求、差异、失败路径和质量命令。
6. 仅在缺少不可推断的业务决策、外部凭据或权限、不可逆生产操作授权时进入外部授权边界。
7. 完成后汇报修改、测试、风险、未验证项和授权状态。
