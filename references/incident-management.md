# 事故响应与复盘

## 事故等级

| 等级 | 定义 |
|---|---|
| SEV0 | 核心业务全面不可用、严重数据丢失或重大安全事件 |
| SEV1 | 核心功能大面积异常 |
| SEV2 | 局部功能或单一渠道异常 |
| SEV3 | 轻微问题或低频异常 |

使用 `SEV0`–`SEV3` 表示事故影响等级；使用 `P0`–`P3` 表示评审发现严重度，不得混用。

## 处理流程

```text
发现告警
→ 确认影响范围
→ 确定等级
→ 指定负责人
→ 控制影响
→ 回滚或修复
→ 验证恢复
→ 通知相关方
→ 完成复盘
→ 跟踪改进项
```

## 复盘内容

- 发生了什么；
- 影响范围和持续时间；
- 事件时间线；
- 根本原因；
- 为什么没有提前发现；
- 为什么影响扩大；
- 哪些机制失效；
- 临时修复；
- 长期改进；
- 责任人和完成期限。

复盘应聚焦系统和流程改进，不只归因于个人失误。
