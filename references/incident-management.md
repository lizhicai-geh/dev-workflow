# 事故响应与复盘

| 等级 | 影响 |
|---|---|
| SEV0 | 核心业务全面不可用、严重数据丢失或重大安全事件 |
| SEV1 | 核心功能大面积异常 |
| SEV2 | 局部功能或单一渠道异常 |
| SEV3 | 轻微或低频异常 |

SEV 表示事故影响，P0–P3 表示评审发现，不得混用。

## 响应

确认影响与等级 → 指定负责人 → 控制影响 → 回滚或修复 → 验证恢复 → 通知相关方 → 复盘并跟踪改进。

优先恢复服务并保存时间线、日志、指标和操作证据；高风险处置需记录决策人。

## 复盘

记录影响和持续时间、时间线、根因、检测缺口、影响扩大的原因、临时/永久修复，以及带负责人和期限的改进项。聚焦系统与流程，不只归因个人失误。
