# 需求风险分级

选择能覆盖影响面的最低等级，并记录命中条件和升级原因。

| 等级 | 典型范围 | 最低交付物 |
|---|---|---|
| L0 | 文案、样式、无业务影响的配置或小改动 | Issue、验收标准 |
| L1 | 单页面、小接口、单一规则、局部权限 | Issue、规则与测试说明 |
| L2 | 跨模块/服务、状态或数据模型、第三方接入、数据范围 | PRD/原型、规则、API/数据设计、任务与测试方案 |
| L3 | 核心架构/状态/安全模型、大迁移、停机或跨团队发布 | 完整设计、ADR、风险、迁移、发布、恢复、监控与独立 AI 验收方案 |

## 自动升级

命中任一项至少升一级：

- 影响多个业务模块或修改核心状态/权限；
- 涉及历史迁移、敏感数据或数据丢失风险；
- 第三方协议变化、停机、灰度、双写或旧版本兼容。

L0/L1 使用直接检查和精简输出；L2 要求正式计划、完整测试与证据；L3 追加架构、迁移、恢复、监控、安全和独立 AI 验收。任何等级都不得把开发或验证步骤转交给用户。
