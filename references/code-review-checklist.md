# 代码审查清单

逐项检查相关内容，不适用项说明原因：

- **业务**：符合需求和规则；状态转换、异常与边界正确；未擅自补造规则。
- **范围**：无无关修改、无意义格式化、重复实现或模块边界破坏。
- **数据**：迁移、索引和事务安全；并发、幂等与历史数据兼容。
- **API**：契约、错误码、分页/排序稳定且向后兼容；外部调用有超时、重试或降级。
- **安全**：服务端鉴权、数据范围和租户隔离正确；无注入、越权、密钥或敏感信息泄露。
- **测试**：覆盖正常、异常、边界、权限及所需的并发/幂等场景；未删除或弱化测试。
- **维护**：命名和抽象清晰；日志可定位；文档同步；TODO 有说明。

## 输出

1. 先列 P0/P1，再列 P2/P3；无发现时明确说明。
2. 每项包含文件/行号、触发条件、影响、证据和最小修复建议。
3. 记录审查范围、提交 SHA、已运行测试、未验证项和剩余风险。
