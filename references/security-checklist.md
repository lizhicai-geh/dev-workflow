# 安全检查清单

## 需求与设计

- [ ] 是否处理个人信息或敏感数据
- [ ] 数据访问角色明确
- [ ] 数据保留和删除策略明确
- [ ] 是否需要审计日志
- [ ] 是否存在租户隔离风险
- [ ] 已考虑越权、重放和参数篡改

## 编码

- [ ] 使用参数化查询
- [ ] 输入校验完整
- [ ] 输出转义正确
- [ ] 文件上传受限
- [ ] 权限在服务端校验
- [ ] 无硬编码密钥
- [ ] 日志无敏感信息

## CI与供应链

- [ ] 密钥扫描
- [ ] 依赖漏洞扫描
- [ ] 静态代码扫描
- [ ] 许可证检查
- [ ] 容器镜像扫描
- [ ] CI令牌最小权限

## 运行

- [ ] 测试与生产权限隔离
- [ ] 生产访问可审计
- [ ] 高风险操作有二次确认
- [ ] 密钥可轮换
- [ ] 异常访问有告警
