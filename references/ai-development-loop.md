# AI 开发循环

## 开始前

- 阅读 `AGENTS.md`、`.ai/workflow-policy.yml`、任务及关联规则；定位现有实现和测试。
- 明确范围、非目标、验收标准、预计文件和验证计划。
- 为每项验收标准绑定自动化验证方式；无法绑定时记录阻断原因。

## 开发中

- 小步修改并复用现有模式，不做无关重构或格式化。
- 规则变化同步补测试；数据库变化新增迁移。
- 不用临时硬编码掩盖问题，不删除或弱化测试。
- 发现计划与事实不符时先更新计划并说明偏差。
- AI 自主处理可恢复失败并保存证据；只有触及外部授权边界才暂停。

## 完成前

按项目实际执行 lint、类型检查、所需层级测试、构建、迁移和安全检查。随后进入独立 AI 验证轮次，重新检查需求映射、失败路径和以下差异：

```bash
git status --short
git diff --stat
git diff
```

最终报告修改、关键决策、计划偏差、测试命令及结果、未执行项及原因、独立验证结论、风险和遗留事项。报告生成后继续执行剩余安全步骤，不把“下一步”留给用户操作。
