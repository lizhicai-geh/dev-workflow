# AI 开发循环

## 开始前

- 阅读 `AGENTS.md`、任务及关联规则；定位现有实现和测试。
- 明确范围、非目标、验收标准、预计文件和验证计划。

## 开发中

- 小步修改并复用现有模式，不做无关重构或格式化。
- 规则变化同步补测试；数据库变化新增迁移。
- 不用临时硬编码掩盖问题，不删除或弱化测试。
- 发现计划与事实不符时先更新计划并说明偏差。

## 完成前

按项目实际执行 lint、类型检查、所需层级测试、构建、迁移和安全检查，并审查：

```bash
git status --short
git diff --stat
git diff
```

最终报告修改、测试命令及结果、未执行项及原因、验收结论、风险和遗留事项。
