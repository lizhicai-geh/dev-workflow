# 发布就绪检查

## 发布前

- [ ] 必需 CI 和 PR 审查通过，版本及变更范围明确
- [ ] staging 验收、环境配置和负责人就绪
- [ ] 数据库迁移及执行顺序已验证
- [ ] 发布策略、恢复方案、监控和告警明确

按风险选择直接、滚动、蓝绿、金丝雀、功能开关或按租户/用户灰度。

## 发布后

- **技术**：成功率、延迟、错误率、资源、数据库、队列和第三方调用正常。
- **业务**：为本系统定义核心流程完成率、处理成功率、转化或对账指标。
- 按观察窗口记录基线、阈值、负责人和验证结论。

## 阻断

存在未接受的 P0/P1、CI 或 staging 失败、迁移不可验证、恢复方案缺失或核心监控缺失时，结论为 No-Go。
