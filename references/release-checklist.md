# 发布就绪检查清单

## 发布前

- [ ] CI全部通过
- [ ] PR审查完成
- [ ] 版本号已确定
- [ ] 变更记录已生成
- [ ] 数据库迁移已验证
- [ ] 环境配置已准备
- [ ] staging已验收
- [ ] 发布负责人明确
- [ ] 恢复方案明确
- [ ] 监控和告警已配置

## 发布策略

根据风险选择：

- 直接发布；
- 滚动发布；
- 蓝绿发布；
- 金丝雀发布；
- 功能开关；
- 按租户、机构或用户比例灰度。

## 发布后技术验证

- 请求成功率；
- 响应时间；
- 错误率；
- CPU和内存；
- 数据库连接和慢查询；
- 队列积压；
- 第三方调用失败率。

## 发布后业务验证

根据系统定义关键业务指标，例如：

- 数据接入量；
- 处理成功率；
- 核心流程完成率；
- 转化率；
- 回传成功率；
- 数据对账差异。

## 阻断条件

- 未关闭 P0/P1；
- 数据迁移不可验证；
- 无恢复方案；
- 核心监控缺失；
- staging 验收失败。
