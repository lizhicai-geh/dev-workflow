# Definition of Done

逐项记录 `通过 / 失败 / 不适用` 及证据：

- **功能**：全部验收标准、主流程、异常、权限、数据范围及所需的幂等/并发要求已满足。
- **代码**：符合规范；无无关改动、调试代码、临时硬编码或未说明债务。
- **测试**：适用的 lint、类型检查、单元/集成/契约/E2E 测试和构建均通过。
- **数据**：迁移已提供并验证；历史数据兼容；修复、对账或补偿方案明确。
- **文档**：业务规则、API、字段字典、发布说明及所需 ADR 已同步。
- **发布**：必需 CI 通过；可部署、可监控、可恢复；已知风险已说明。

任一必需项失败或缺少证据时不得判定完成；不适用项必须说明依据。
