# Definition of Done 检查清单

## 功能

- [ ] 满足全部验收标准
- [ ] 主流程可用
- [ ] 异常流程已处理
- [ ] 权限和数据范围正确
- [ ] 幂等和并发要求满足

## 代码

- [ ] 代码符合规范
- [ ] 无无关修改
- [ ] 无调试代码
- [ ] 无临时硬编码
- [ ] 无未说明技术债务

## 测试

- [ ] lint 通过
- [ ] typecheck 通过
- [ ] 单元测试通过
- [ ] 集成测试通过
- [ ] 契约测试通过或不适用
- [ ] 构建通过

## 数据

- [ ] 迁移脚本已提供
- [ ] 迁移已验证
- [ ] 历史数据兼容
- [ ] 数据修复或补偿方案明确

## 文档

- [ ] 业务规则已更新
- [ ] API文档已更新
- [ ] 字段字典已更新
- [ ] 发布说明已更新
- [ ] ADR按需补充

## 发布

- [ ] CI全部通过
- [ ] 可部署
- [ ] 可监控
- [ ] 有恢复方案
- [ ] 已说明已知风险
